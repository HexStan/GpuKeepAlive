# deprecated - 已废弃脚本归档

> **⚠️ 本目录已废弃，不再维护。**
>
> 目录内所有文件仅作历史归档保留，不会再接收任何更新或修复，请勿在新环境中继续依赖。

## 目录内容

| 文件 | 说明 |
| :--- | :--- |
| `启动核显保活.ps1` | 早期前台启动脚本（内部写死 `-a intel -f 15 -i 1` 默认参数） |
| `启动核显保活(后台静默).vbs` | 早期后台静默启动脚本（同样写死 `-a intel` 默认参数） |
| `停止核显保活.ps1` | 停止后台运行的保活进程 |
| `gpu_keepalive.py` | 纯 Python + 系统 OpenGL 版保活脚本（零第三方依赖） |

## 现行方案

上述脚本默认绑定特定厂商显卡（`-a intel`）的做法已随项目定位调整而弃用。现行版本为项目根目录的 **`GpuKeepAlive.exe`**——不预设、不默认绑定任何显卡类型，目标显卡由用户通过命令行参数或 Windows 图形首选项自行指定，详见 [根目录 README](../README.md)。
